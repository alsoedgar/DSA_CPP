# C++ Data Structures & Algorithms Journey

Helloooo, my name is Edgar and this is my journey to learn basic data structures and algorithms! I want to learn DSA to prepare for technical interviews and personal projects, so this is my testing playground to learn and explore! 

My goal is to deep-dive into DSA to sharpen my problem-solving skills! To fully grasp how these concepts function under the hood, **I am implementing every data structure and algorithm entirely from scratch**, avoiding the C++ Standard Template Library (STL). >:D

---

## 🛠️ What I am Building & Learning

### Data Structures
* **Linear:** Stacks, Queues, Doubly/Singly Linked Lists
* **Non-Linear:** Trees (BST, AVL, RBT), Heaps, and Graphs
* **Hashing:** Hashmaps (Chaining & Open Addressing implementations)

### Algorithms
* **Searching:** Linear Search, Binary Search, BFS, and DFS
* **Sorting:** Bubble Sort, Selection Sort, Insertion Sort, Merge Sort, Quicksort
* **Graph:** Shortest path pathfinding (Dijkstra's), and MST (Prims)
